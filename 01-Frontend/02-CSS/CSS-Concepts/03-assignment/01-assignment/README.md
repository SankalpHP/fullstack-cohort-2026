## 🎨 Fonts & Colors Used

### Colors
- **Primary Background:** `#08090B`
- **Primary Text (White):** `#FFFFFF`
- **Accent / Brand Green:** `#18E299`
- **Secondary Green:** `#0C8C5E`
- **Muted Text:** `lab(100 0 0 / 0.7)`

### Design Choices
- Dark theme to match modern SaaS documentation platforms
- Green accent color used for highlights, tags, and call-to-action elements
- Rounded corners and soft borders for a clean UI feel
